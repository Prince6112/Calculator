# Calculator

A simple calculator web app built with plain HTML, CSS, and JavaScript. No build step or dependencies required.

## Usage

Open `index.html` in any modern web browser.

## Features

- Digit entry (0–9)
- Addition, subtraction, multiplication, and division
- `=` to evaluate the current expression
- `AC` to clear everything

## Known limitations

- The decimal point (`.`) and percentage (`%`) buttons are present in the UI but not yet wired up.
- Calculations use `parseInt`, so results are based on whole numbers only.

## Project structure

| File             | Purpose                              |
| ---------------- | ------------------------------------ |
| `index.html`     | Calculator markup                    |
| `stylesheet.css` | Styling and layout                   |
| `script.js`      | Input handling and calculation logic |
