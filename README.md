# Calculator

A simple calculator web app built with plain HTML, CSS, and JavaScript. No build step or dependencies required.

## Usage

Open `index.html` in any modern web browser.

## Features

- Digit entry (0–9) and decimal numbers
- Addition, subtraction, multiplication, and division
- `=` to evaluate the current expression
- `AC` to clear everything

## Known limitations

- The percentage (`%`) button is present in the UI but not yet wired up.

## Project structure

| File             | Purpose                              |
| ---------------- | ------------------------------------ |
| `index.html`     | Calculator markup                    |
| `stylesheet.css` | Styling and layout                   |
| `script.js`      | Input handling and calculation logic |
